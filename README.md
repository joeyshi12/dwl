# dwl

My build of [dwl](https://codeberg.org/dwl/dwl) 0.9 for my Arch Linux system. It needs the
`wlroots0.20` and `scenefx` packages. The first commit is the upstream v0.9 tree with these
changes applied:

| Change | What it is |
|---|---|
| ipc | [ipc](https://codeberg.org/dwl/dwl-patches/src/branch/main/patches/ipc) from dwl-patches. The [wakeshell](https://github.com/joeyshi12/wakeshell) bar uses it to read tags, layout and title and to switch tags on click. |
| movestack | Alt+Shift+j/k moves the focused window in the stack |
| ipc zoom | Adds a zoom request to the ipc protocol (version 3) so middle-clicking the title in the bar runs zoom. Also stops the ipc patch from announcing its global twice. |
| scenefx corners | Draws through [scenefx](https://github.com/wlrfx/scenefx) to round window corners and borders. `cornerradius` in `config.h` sets the radius; fullscreen windows stay square. |
| Window shadows | A hard shadow (scenefx) offset down and right under floating windows, set by `shadowoffset` and `shadowcolor` in `config.h` (0 turns it off) |
| Urgent on hidden tags | A window that opens on a tag that is not being viewed (for example from a rule) is marked urgent, so the bar highlights that tag until the window is focused |
| `config.h` | Keybindings, rules, borders and input settings |
| `colors.h` | Generated by `scripts/theme.sh` in [my dotfiles](https://github.com/joeyshi12/dotfiles). Do not edit. |
| `config.mk` | Xwayland enabled |

## Install

```sh
make
sudo make install
```

This builds with Xwayland and installs to `/usr/local/bin/dwl`. Run it again after changing
`config.h` or the theme.

## Updating to a new dwl release

This repository does not share history with upstream, but its files match the upstream v0.9 tree
apart from the changes above, so upstream changes can be applied as a diff between two tags:

```sh
git fetch --no-tags https://codeberg.org/dwl/dwl.git tag v0.9 tag v0.10
git diff v0.9 v0.10 | git apply -3
```

Resolve any conflicts, then:

1. Check which wlroots the release targets in `config.mk`. scenefx must have a release for the
   same wlroots version; set its version in `PKGS` in the `Makefile`.
2. If the ipc protocol changed, check dwl-patches for an updated ipc patch and copy the new
   `protocols/dwl-ipc-unstable-v2.xml` into wakeshell.
3. Compare `config.h` with the new `config.def.h` and add any new settings.
4. Run `make` and `sudo make install`.

To see everything this build changes relative to upstream, run `git diff v0.9 HEAD`.
